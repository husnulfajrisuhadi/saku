Kebijakan Privasi Saku

Berlaku sejak 11 November 2026 · Kembali ke Saku

Saku adalah pemutar musik web untuk file lagu milik pengguna sendiri. Halaman ini menjelaskan data apa yang dipakai Saku dan bagaimana.

Lagu di perangkat

Lagu yang kamu tambahkan disimpan di penyimpanan browser perangkatmu sendiri (IndexedDB). File itu tidak dikirim ke server Saku. Saku tidak punya server penyimpanan sendiri.

Login Google dan Google Drive (opsional)

Kalau kamu memilih masuk dengan Google, Saku meminta izin berikut:

  • Alamat email dan nama profil: hanya untuk menampilkan akun yang sedang masuk di aplikasi.
  • Google Drive (drive.file): untuk membuat folder "Saku" di Google Drive kamu, mengunggah lagu yang kamu pilih ke folder itu, menampilkan daftarnya, mengunduhnya kembali, dan menghapusnya atas perintahmu.

Dengan izin drive.file, Saku hanya bisa mengakses file yang dibuat oleh Saku. File lain di Google Drive kamu tidak bisa dilihat atau diubah.

Semua komunikasi dengan Google terjadi langsung dari browsermu ke Google. Token akses disimpan sementara di browsermu dan tidak dikirim ke pihak mana pun selain Google.

Penggunaan data

  • Data Google hanya dipakai untuk fitur penyimpanan dan pemutaran lagu di Saku.
  • Saku tidak menjual, membagikan, atau memakai data untuk iklan.
  • Saku tidak memakai data Google untuk melatih model AI.
  • Saku tidak memasang pelacak atau analitik.

Penggunaan dan pemindahan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus data

  • Hapus lagu di perangkat lewat MENU → Kosongkan perangkat.
  • Hapus lagu di Google Drive lewat MENU → Hapus semua di Google Drive, atau hapus folder "Saku" langsung di Drive.
  • Cabut akses Saku kapan saja di myaccount.google.com/permissions.
